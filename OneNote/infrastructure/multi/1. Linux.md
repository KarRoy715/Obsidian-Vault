1. **ls -l** **输出详细解释**

**例子：**-rwxr-x--- 1 ai pp 4096 Jan 22 10:30 somefile

**1.1** **第一个字符**

| **字符** | **含义** |
| --- | --- |
| - | 普通文件 |
| d | 目录 |
| l | 软链接 |
| c | 字符设备 |
| b | 块设备 |

**1.2** **后 9 个字符：权限（分 3 组）**

| **段** | **对象** | **含义** |
| --- | --- | --- |
| rwx | 用户(owner) | ai 的权限 |
| r-x | 用户组(group) | pp 组的权限 |
| --- | 其他人(others) | 其他用户权限 |

～：在 Unix/Linux/macOS 系统中，～ 是一个特殊符号，代表当前登录用户的主目录（home directory）。

例如，如果你的用户名是 alice，那么 ～ 通常等价于 /home/alice（Linux）或 /Users/alice（macOS）。
