## 一、torchrun

1. CUDA_VISIBLE_DEVICES=0,1,2,3 torchrun --nproc_per_node=4 .....
`torchrun` 内部会**启动 4 个独立的 Python 进程**，每个进程自动带上不同的环境变量。
`--nproc_per_node=4` 表示在当前机器上启动 4 个进程。它们都会各自执行一次完整的后面脚本

| 环境变量          | 进程 0        | 进程 1        | 进程 2 | 进程 3 |
| ------------- | ----------- | ----------- | ---- | ---- |
| `RANK`        | `0`         | `1`         | `2`  | `3`  |
| `LOCAL_RANK`  | `0`         | `1`         | `2`  | `3`  |
| `WORLD_SIZE`  | `4`         | `4`         | `4`  | `4`  |
| `MASTER_ADDR` | `127.0.0.1` | `127.0.0.1` | ...  | ...  |
| `MASTER_PORT` | `29517`     | `29517`     | ...  | ...  |
- **`RANK`**：全局编号，0 到 world_size-1
- **`LOCAL_RANK`**：本机编号，对应哪张 GPU（`torch.cuda.set_device(local_rank)` 就用它）
- **`WORLD_SIZE`**：总进程数（这里是一台机器 4 张卡，所以是 4）
