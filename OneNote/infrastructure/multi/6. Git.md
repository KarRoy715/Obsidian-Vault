1. 用ssh连接远程仓库
- 查看现在的连接网址：git remote -v
- 如果看到类似如下：

origin  https://github.com/username/repo.git (fetch)

origin  https://github.com/username/repo.git (push)

- 修改为ssh网址
- git remote set-url origin git@github.com:username/repo.git
- 验证修改：git remote -v

二、常用指令
##### 1. git branch -m main V0.0
- git branch :  分支管理
- -m : move，重命名（-M：如果分支已经存在，则强制覆盖）
- main：原分支名
- V0.0：新分支名
##### 2. git checkout -b main
- git checkout：切换分支
- -b：branch，新分支
- main：新分支名称
