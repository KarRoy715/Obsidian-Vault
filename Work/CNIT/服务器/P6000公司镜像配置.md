## 1. 配置 pip 全局镜像源
```shell
tee /etc/pip.conf > /dev/null <<'EOF'
[global]
index-url = http://10.213.196.151/pypi/web/simple
trusted-host = 10.213.196.151
EOF
```

## 2. 配置 apt 的 Ubuntu 镜像源

```bash
tee /etc/apt/sources.list.d/ubuntu.sources > /dev/null <<'EOF'
Types: deb
URIs: http://10.213.196.151/ubuntu/
Suites: noble noble-updates noble-security noble-backports
Components: main restricted universe multiverse
Signed-By: /usr/share/keyrings/ubuntu-archive-keyring.gpg
EOF
```

## 3. 注释掉 CUDA 源，避免 apt update 报错/警告
```bash
grep -rl developer.download.nvidia.com /etc/apt/sources.list.d/ \
  | xargs -r sed -i 's/^deb /#deb /'
```

## 4. 刷新 apt 软件包索引
```shell
apt update
```

## 5. 临时设置 uv 的镜像源
```bash
export UV_DEFAULT_INDEX=http://10.213.196.151/pypi/web/simple
export UV_INDEX_URL=http://10.213.196.151/pypi/web/simple
export UV_INSECURE_HOST=10.213.196.151
```

uv安装
```
python3 -m pip install --break-system-packages uv
```
